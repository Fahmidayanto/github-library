Tentang

vLLM adalah perpustakaan yang cepat dan mudah digunakan untuk inferensi dan penyajian LLM.

Awalnya dikembangkan di Lab Komputasi Langit di UC Berkeley, vLLM telah berkembang menjadi salah satu proyek AI sumber terbuka paling aktif yang dibangun dan dikelola oleh beragam komunitas yang terdiri dari lusinan institusi akademis dan perusahaan dari lebih dari 2000 kontributor.

vLLM cepat dengan:

  • Throughput penyajian yang canggih
  • Manajemen kunci perhatian dan memori nilai yang efisien dengan PagedPerhatian
  • Pengelompokan permintaan masuk yang berkelanjutan, pengisian awal yang terpotong, cache awalan
  • Eksekusi model yang cepat dan fleksibel dengan grafik CUDA/HIP sepotong-sepotong dan penuh
  • Kuantisasi: FP8, MXFP8/MXFP4, NVFP4, INT8, INT4, GPTQ/AWQ, GGUF, tensor terkompresi, ModelOpt, TorchAO, dan lebih
  • Kernel perhatian yang dioptimalkan termasuk FlashAttention, FlashInfer, TRTLLM-GEN, FlashMLA, dan Triton
  • Kernel GEMM/MoE yang dioptimalkan untuk berbagai presisi menggunakan CUTLASS, TRTLLM-GEN, CuTeDSL
  • Decoding spekulatif termasuk n-gram, suffix, EAGLE, DFlash
  • Pembuatan kernel otomatis dan transformasi tingkat grafik menggunakan torch.compile
  • Pra-pengisian, dekode, dan enkode terpilah

vLLM fleksibel dan mudah digunakan dengan:

  • Integrasi yang mulus dengan model Hugging Face yang populer
  • Penyajian throughput tinggi dengan berbagai algoritma decoding, termasuk pengambilan sampel paralel, pencarian sinar, dan banyak lagi
  • Tensor, pipeline, data, pakar, dan paralelisme konteks untuk inferensi terdistribusi
  • Keluaran streaming
  • Pembuatan keluaran terstruktur menggunakan xgrammar atau panduan
  • Pemanggilan alat dan parser penalaran
  • Server API yang kompatibel dengan OpenAI, ditambah API Pesan Antropik dan dukungan gRPC
  • Dukungan multi-LoRA yang efisien untuk lapisan padat dan MoE
  • Dukungan untuk GPU NVIDIA, GPU AMD, GPU Intel, dan CPU x86/ARM/PowerPC. Selain itu, beragam plugin perangkat keras seperti Google TPU, Intel Gaudi, IBM Spyre, Huawei Ascend, Rebellions NPU, Apple Silicon, MetaX GPU, dan banyak lagi.

vLLM dengan lancar mendukung 200+ arsitektur model di Hugging Face, termasuk:

  • LLM khusus decoder (misalnya, Llama, Qwen, Gemma)
  • LLM Campuran Pakar (misalnya, Mixtral, DeepSeek-V3, Qwen-MoE, GPT-OSS)
  • Model perhatian hibrida dan ruang negara (misalnya, Mamba, Qwen3.5)
  • Model multi-modal (misalnya, LLaVA, Qwen-VL, Pixtral)
  • Model penyematan dan pengambilan (misalnya, E5-Mistral, GTE, ColBERT)
  • Model penghargaan dan klasifikasi (misalnya, Qwen-Math)

Temukan daftar lengkap model yang didukung di sini.

Memulai

Instal vLLM dengan uv (disarankan) atau pip:

uv pip install vllm
vllm download-kernels  # precompiled kernels for faster startup

Atau membangun dari sumber untuk pengembangan.
