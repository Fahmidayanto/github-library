Kekuatan super

Kekuatan Super adalah metodologi pengembangan perangkat lunak lengkap untuk agen pengkodean Anda, yang dibangun di atas serangkaian keterampilan yang dapat disusun dan beberapa instruksi awal yang memastikan agen Anda menggunakannya.

Bagaimana cara kerjanya

Ini dimulai dari saat Anda menjalankan agen pengkodean Anda. Segera setelah ia melihat bahwa Anda sedang membangun sesuatu, itu tidak langsung saja mencoba menulis kode. Sebaliknya, ia mundur dan menanyakan apa yang sebenarnya Anda coba lakukan.

Setelah ia mengeluarkan suatu spesifikasi dari percakapan, ia akan menunjukkannya kepada Anda dalam potongan-potongan yang cukup pendek untuk benar-benar dibaca dan dicerna.

Setelah Anda menandatangani desainnya, agen Anda menyusun rencana implementasi yang cukup jelas bagi seorang insinyur junior yang antusias dengan selera buruk, tidak ada penilaian, tidak ada konteks proyek, dan keengganan untuk mengikuti pengujian. Ini menekankan TDD merah/hijau sejati, YAGNI (Anda Tidak Akan Membutuhkannya), dan KERING.

Selanjutnya, setelah Anda mengucapkan "pergi", a pengembangan yang didorong oleh subagen proses, meminta agen mengerjakan setiap tugas teknik, memeriksa dan meninjau pekerjaan mereka, dan melanjutkan ke depan. Bukan hal yang aneh jika agen Anda bekerja secara mandiri selama beberapa jam tanpa menyimpang dari rencana yang Anda buat.

Masih banyak lagi, tapi itulah inti sistemnya. Dan karena keterampilannya terpicu secara otomatis, Anda tidak perlu melakukan sesuatu yang khusus. Agen pengkodean Anda hanya memiliki Kekuatan Super.

Layanan Komersial

Jika Anda menggunakan Kekuatan Super dalam perusahaan dan dapat memperoleh manfaat dari dukungan komersial, peralatan tambahan, atau pengeluaran terkelola, jangan ragu untuk menghubungi kami di penjualan@primeradiant.com.

Instalasi

Pemasangan berbeda tergantung harness. Jika Anda menggunakan lebih dari satu, instal Kekuatan Super secara terpisah untuk masing-masingnya.

Kode Claude

Kekuatan super tersedia melalui pasar plugin Claude resmi

Pasar Resmi

  • Instal plugin dari pasar resmi Anthropic:

    /plugin install superpowers@claude-plugins-official

Pasar Kekuatan Super

Pasar Superpowers menyediakan Superpowers dan beberapa plugin terkait lainnya untuk Claude Code.

  • Daftarkan pasar:

    /plugin marketplace add obra/superpowers-marketplace

  • Instal plugin dari pasar ini:

    /plugin install superpowers@superpowers-marketplace

Antigravitasi

Instal Superpowers sebagai plugin dari repositori ini:

agy plugin install https://github.com/obra/superpowers

Antigravitasi mencantumkan deskripsi setiap keterampilan yang dipasang, dan deskripsinya keterampilan using-superpowers meminta model memuat keterampilan itu di awal dari sebuah percakapan. Instal ulang dengan perintah yang sama untuk memperbarui.

Aplikasi Kodeks

Kekuatan super tersedia melalui pasar plugin Codex resmi.

  • Di aplikasi Codex, klik Plugins di sidebar.
  • Anda akan melihat Superpowers di bagian Coding.
  • Klik + di sebelah Kekuatan Super dan ikuti petunjuknya.

Kodeks CLI

Kekuatan super tersedia melalui pasar plugin Codex resmi.

  • Buka antarmuka pencarian plugin:

    /plugins

  • Pencarian Kekuatan Super:

    superpowers

  • Pilih Install Plugin.

Kursor

  • Dalam obrolan Agen Kursor, instal dari pasar:

    /add-plugin superpowers

  • Atau cari "kekuatan super" di pasar plugin.

Devin CLI

  • Instal plugin dari repositori ini:

    devin plugins install obra/superpowers

  • Perbarui ke versi terbaru dengan:

    devin plugins update superpowers

Pabrik Droid

  • Daftarkan pasar:

    droid plugin marketplace add https://github.com/obra/superpowers

  • Instal pluginnya:

    droid plugin install superpowers@superpowers

CLI Gemini

  • Instal ekstensi:

    gemini extensions install https://github.com/obra/superpowers

  • Perbarui nanti:

    gemini extensions update superpowers

CLI Kopilot GitHub

  • Daftarkan pasar:

    copilot plugin marketplace add obra/superpowers-marketplace

  • Instal pluginnya:

    copilot plugin install superpowers@superpowers-marketplace

Grok Bangun CLI

Kekuatan super tersedia melalui pasar plugin Grok resmi.

  • Instal plugin dari pasar resmi xAI:

    grok plugin install superpowers@xai-official --trust

  • Atau buka pasar di TUI, cari Kekuatan Super, dan instal:

    /marketplace

Kode Kimi

Kekuatan super tersedia di pasar plugin Kimi Code.

  • Buka manajer plugin Kimi Code:

    /plugins

  • Buka Marketplace > Superpowers dan instal.

  • Atau instal langsung dari repositori ini:

    /plugins install https://github.com/obra/superpowers

  • Dokumen terperinci: dokumen/README.kimi.md

Kode Terbuka

OpenCode menggunakan instalasi pluginnya sendiri; instal Kekuatan Super secara terpisah meskipun Anda sudah menggunakannya di harness lain.

  • Beritahu OpenCode:

    Fetch and follow instructions from https://raw.githubusercontent.com/obra/superpowers/refs/heads/main/.opencode/INSTALL.md

  • Dokumen terperinci: dokumen/README.opencode.md

pi

Instal Kekuatan Super sebagai paket Pi dari repositori ini:

pi install git:github.com/obra/superpowers

Untuk pengembangan lokal, jalankan Pi dengan checkout ini dimuat sebagai paket sementara:

pi -e /path/to/superpowers

Paket Pi memuat keterampilan Kekuatan Super dan ekstensi kecil yang memasukkan bootstrap using-superpowers pada permulaan sesi dan lagi setelah pemadatan. Pi memiliki keterampilan asli, jadi tidak diperlukan alat Skill kompatibilitas. Alat subagen dan daftar tugas tetap menjadi paket pendamping Pi opsional.

Kode Qwen

Qwen Code menginstal plugin dari pasar Claude Code secara langsung.

  • Instal plugin dari repositori ini, dan pilih superpowers ketika diminta:

    qwen extensions install obra/superpowers

  • Perbarui nanti:

    qwen extensions update superpowers

Agen Hermes

Instal Superpowers sebagai plugin Hermes dari repositori ini:

hermes plugins install obra/superpowers --enable

Mulai ulang sesi Hermes yang aktif setelah instalasi. Catatan: Hermes tidak punya kait pasca-pemadatan, jadi sesi yang sangat panjang yang memadat dari sesi pertama giliran kehilangan bootstrap — mulai sesi baru jika keterampilan berhenti terpicu.

Renungan

Kekuatan super tersedia sebagai plugin Muse asli — repo yang sama, keterampilan yang sama, semua pemanfaatan. Bootstrap using-superpowers dimasukkan melalui hook asli SessionStart bersama Claude Code, Codex, Cursor, Gemini, Pi, dan lainnya — tidak ada keikutsertaan per sesi.

  • Instal dari checkout lokal:

    muse plugins install ./
muse plugins approve superpowers

    Atau kloning dan instal:

    git clone https://github.com/obra/superpowers.git
muse plugins install ./superpowers
muse plugins approve superpowers

  • Perbarui nanti:

    muse plugins update superpowers

Mulai ulang setiap sesi Muse yang aktif setelah instalasi sehingga kait SessionStart berlaku — keterampilan segera aktif, kait memerlukan persetujuan pada instalasi pertama. Untuk memverifikasi, mulai sesi baru dan kirim Let's make a react todo list — penginstalan yang berfungsi memicu otomatis brainstorming sebelum kode apa pun ditulis. Versi dilacak dalam .version-bump.json jadi scripts/bump-version.sh tetap menyinkronkannya.

Alur Kerja Dasar

  1. bertukar pikiran - Aktifkan sebelum membangun apa pun. Gambarkan apa yang sebenarnya Anda inginkan, dan alasannya, melalui pertanyaan yang membuat Anda mendeskripsikannya, lalu memutar kembali pemahamannya untuk dikoreksi. Perubahan kecil disetujui dalam obrolan; proyek mendapatkan dokumen desain tertulis yang dapat direncanakan oleh pembangun.

  2. menggunakan-git-worktrees - Diaktifkan setelah persetujuan desain. Membuat ruang kerja terisolasi di cabang baru, menjalankan penyiapan proyek, memverifikasi garis dasar pengujian yang bersih.

  3. rencana penulisan - Diaktifkan dengan desain yang disetujui. Bagi pekerjaan menjadi tugas-tugas kecil (masing-masing 2-5 menit). Setiap tugas memiliki jalur file yang tepat, kode lengkap, langkah verifikasi.

  4. pengembangan yang didorong oleh subagen atau rencana pelaksanaan - Diaktifkan dengan rencana. Baik mengirimkan subagen baru per tugas dengan peninjauan setelah setiap tugas (paling menyeluruh), atau mengimplementasikan setiap tugas sebaris dalam sesi saat ini dengan satu peninjauan baru untuk seluruh cabang di akhir (termurah).

  5. pengembangan yang didorong oleh pengujian - Aktif selama implementasi. Menerapkan RED-GREEN-REFACTOR: tulis tes yang gagal, lihat gagal, tulis kode minimal, lihat lulus, komit. Menghapus kode yang ditulis sebelum pengujian.

  6. meminta-peninjauan kode - Mengaktifkan antar tugas. Meninjau terhadap rencana, melaporkan masalah berdasarkan tingkat keparahan. Permasalahan kritis menghambat kemajuan.

  7. menyelesaikan-cabang-pengembangan - Aktif saat tugas selesai. Memverifikasi pengujian, menyajikan opsi (gabungkan/PR/simpan/buang), bersihkan pohon kerja.

Agen memeriksa keterampilan yang relevan sebelum melakukan tugas apa pun. Alur kerja wajib, bukan saran.

Ketika Sesuatu Terjadi Salah

Terkadang suatu sesi berperilaku buruk: keterampilan diaktifkan pada saat yang tidak seharusnya, tetap diam pada saat yang seharusnya, atau agen mengabaikan rencananya, mengulangi pekerjaan, atau membakar lebih banyak token daripada yang Anda harapkan. Minta agen pengkodean Anda untuk "mencari tahu apa yang salah dengan negara adidaya di sesi ini" dan agen tersebut akan memanggil mendiagnosis-kekuatan super keterampilan. Untuk memeriksa sesi sebelumnya, beri nama: "cari tahu apa yang salah dengan negara adidaya di sesi <id>".

Keterampilan membaca transkrip sesi, melaporkan apa yang terjadi dengan bukti tingkat baris, dan, jika Anda mau, mengemas bundel yang telah dihapus untuk laporan bug.

Apa yang ada di dalamnya

Perpustakaan Keterampilan

Pengujian

  • pengembangan yang didorong oleh pengujian - Siklus MERAH-HIJAU-REFACTOR (termasuk pengujian referensi anti-pola)

Men-debug

  • debugging sistematis - Proses akar penyebab 4 fase (termasuk penelusuran akar penyebab, pertahanan mendalam, teknik menunggu berbasis kondisi)
  • verifikasi-sebelum-penyelesaian - Pastikan itu benar-benar diperbaiki
  • mendiagnosis-kekuatan super - Cari tahu apa yang salah dalam suatu sesi, dengan bukti; ekspor bundel yang dihapus atau ajukan masalah

Kolaborasi

  • bertukar pikiran - Menggambarkan niat sebelum membangun
  • rencana penulisan - Rencana implementasi terperinci
  • rencana pelaksanaan - Eksekusi rencana sebaris: satu konteks, satu tinjauan akhir
  • agen pengiriman-paralel - Alur kerja subagen secara bersamaan
  • meminta-peninjauan kode - Daftar periksa pra-tinjauan
  • menerima-kode-review - Menanggapi umpan balik
  • menggunakan-git-worktrees - Cabang pengembangan paralel
  • menyelesaikan-cabang-pengembangan - Alur kerja keputusan penggabungan/PR
  • pengembangan yang didorong oleh subagen - Iterasi cepat dengan tinjauan dua tahap (kepatuhan spesifikasi, lalu kualitas kode)

Meta

  • keterampilan menulis - Ciptakan keterampilan baru dengan mengikuti praktik terbaik (termasuk metodologi pengujian)
  • menggunakan kekuatan super - Pengenalan sistem keterampilan

Filsafat

  • Pengembangan Berbasis Tes - Tulis tes terlebih dahulu, selalu
  • Sistematis dan ad-hoc - Proses menebak-nebak
  • Pengurangan kompleksitas - Kesederhanaan sebagai tujuan utama
  • Bukti atas klaim - Verifikasi sebelum menyatakan sukses

Berkontribusi

Proses kontribusi umum untuk Negara Adidaya ada di bawah. Ingatlah bahwa pada umumnya kami tidak menerima kontribusi keterampilan baru dan setiap pembaruan keterampilan harus dilakukan di semua agen pengkodean yang kami dukung.

  1. Cabangkan repositori
  2. Beralih ke cabang 'dev'
  3. Buat cabang untuk pekerjaan Anda
  4. Ikuti keterampilan writing-skills untuk membuat dan menguji keterampilan baru dan yang dimodifikasi
  5. Kirimkan PR, pastikan untuk mengisi template permintaan tarik.

Tes keterampilan-perilaku menggunakan latihan eval harness dari evaluasi kekuatan super, diklon ke evals/ — lihat evals/README.md untuk pengaturan. Pengujian infrastruktur plugin dilakukan di tests/ dan dijalankan melalui run-*.sh atau npm test yang relevan.

Lihat skills/writing-skills/SKILL.md untuk panduan lengkapnya.

Telemetri pendamping visual

Karena keterampilan dan plugin tidak memberikan masukan apa pun kepada pembuat konten, kami tidak tahu berapa banyak dari Anda yang menggunakan Kekuatan Super. Secara default, logo Prime Radiant pada fitur pendamping visual opsional brainstorming dimuat dari situs web kami. Ini termasuk versi Kekuatan Super yang digunakan. Itu tidak mencakup detail apa pun tentang proyek, prompt, atau agen pengkodean Anda. Kami tidak melihat klik Anda atau apa pun tentang apa yang Anda buat. Ini membantu kami mendapatkan gambaran kasar tentang berapa banyak orang yang menggunakan Kekuatan Super dan versi Kekuatan Super mana yang mereka gunakan. Ini 100% opsional. Untuk menonaktifkan ini, setel variabel lingkungan SUPERPOWERS_DISABLE_TELEMETRY ke nilai sebenarnya. Negara adidaya juga menghormati pilihan tidak ikut serta DISABLE_TELEMETRY dan CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC Claude Code.
