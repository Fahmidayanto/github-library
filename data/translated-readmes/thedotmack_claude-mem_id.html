Sistem kompresi memori persisten yang dibangun untuk Claude Code.

Quick Start • Cara Kerja • Search Tools • Dokumentasi • Konfigurasi • Troubleshooting • Lisensi

Claude-Mem secara mulus mempertahankan konteks antar sesi dengan secara otomatis menangkap observasi penggunaan tool, menghasilkan ringkasan semantik, dan membuatnya tersedia untuk sesi mendatang. Hal ini memungkinkan Claude untuk mempertahankan kontinuitas pengetahuan tentang proyek bahkan setelah sesi berakhir atau terhubung kembali.

Quick Start

Instal claude-mem untuk Grok Bot:

npx claude-mem install --ide grok-bot

Grok Bot tidak memiliki host hooks, jadi kami memantau file log chat. Default adalah CMEM Pro, memori yang di-host. Local observer bersifat opt-in: --provider host. Instalasi plugin ini tidak menginstal Cursor.

Pilot awareness push (LFG + Orifice): observasi needle (decision, bugfix, security_alert, sensitive) ditambahkan sebagai baris - YYYY-MM-DD [awareness] … bertanggal ke memory/log/YYYY-MM.md bot tersebut. Grok Bot sudah membaca ulang log dari disk. Ini tidak menulis profile.md, user-memory, atau project memory. Nonaktifkan dengan CLAUDE_MEM_GROK_BOT_AWARENESS_ENABLED=false.

Instal dengan satu perintah:

npx claude-mem install

Installer akan menyiapkan semuanya terlebih dahulu, lalu meminta Anda untuk masuk ke claude-mem di browser (magic link email — tidak diperlukan kartu). Masuk akan menyediakan memory key untuk akun Anda dan membuka kunci claude-mem observer dengan 30 Day Free Trial: memory berjalan di luar paket, sehingga Anda mendapatkan hingga 100% lebih banyak penggunaan dari paket Anda. Ketika uji coba gratis berakhir, memory secara otomatis kembali ke paket Anthropic Anda kecuali Anda berlangganan. Setelah masuk, Anda memilih penyedia memory — claude-mem observer, kunci OpenRouter atau Gemini Anda sendiri, atau paket Anthropic Anda.

Lebih suka melewati proses masuk? Sampaikan flag --provider secara eksplisit, atur CLAUDE_MEM_ONLINE_OPTIN=false, atau jalankan di shell CI/non-interactive — installer akan selesai tanpa interaksi akun apa pun.

Atau instal untuk OpenCode:

npx claude-mem install --ide opencode

Ini berfungsi dengan OpenCode 1.3.4 atau lebih baru, termasuk OpenCode 2. Restart OpenCode setelah instalasi.

Atau instal untuk T3 Code (penyedia Codex dan Claude Code):

npx claude-mem install --ide t3code

Installer mendeteksi provider yang diaktifkan di T3 Code, mendaftarkan plugin Claude-Mem native di lokasi konfigurasi masing-masing, dan mendukung Codex yang dikelola T3. Restart T3 Code, percaya pada hooks provider saat diminta, dan mulai thread baru. Lihat panduan integrasi T3 Code untuk pengaturan server kustom, status, dan penghapusan.

Atau install untuk Antigravity CLI (panduan setup):

npx claude-mem install --ide antigravity

Atau install untuk OMP (Oh My Pi):

npx claude-mem install --ide omp

Atau install ekstensi Pi native atau plugin DeepSeek Harness:

npx claude-mem install --ide pi
npx claude-mem install --ide dsh --dsh-profile tui

Pi dan DeepSeek Harness menggunakan worker runtime. Lihat setup harness native untuk capture, recall, dan troubleshooting.

Atau install dari plugin marketplace di dalam Claude Code:

/plugin marketplace add thedotmack/claude-mem

/plugin install claude-mem

Restart Claude Code. Konteks dari sesi sebelumnya akan secara otomatis muncul di sesi baru.

Catatan: Claude-Mem juga dipublikasikan di npm, tetapi npm install -g claude-mem hanya menginstall SDK/library — tidak mendaftarkan plugin hooks atau mengatur worker service. Selalu install melalui npx claude-mem install atau perintah /plugin di atas.

Cara Kerja

Komponen Inti:

  1. Lifecycle Hooks - SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop, SessionEnd. Masing-masing adalah satu perintah tanpa shell, claude-mem hook claude-code <event>, yang dijalankan oleh launcher kecil yang dipasang installer ke PATH
  2. Smart Install - Pengecek dependensi yang di-cache (Setup hook di claude --init / --maintenance, serta npx claude-mem install / repair)
  3. Worker Service - API HTTP lokal dengan UI web viewer dan endpoint pencarian, dikelola oleh Bun
  4. Database SQLite - Menyimpan sesi, observasi, dan ringkasan
  5. Skill mem-search - Kueri bahasa alami dengan progressive disclosure
  6. Chroma Vector Database - Pencarian hibrida semantik + kata kunci untuk pengambilan konteks yang cerdas

MCP Search Tools

Claude-Mem menyediakan pencarian memori yang cerdas melalui 4 MCP tools mengikuti pola workflow 3-lapisan:

Workflow 3-Lapisan:

  1. search - Dapatkan indeks ringkas dengan ID (~50-100 token/hasil)
  2. timeline - Dapatkan konteks kronologis di sekitar hasil yang menarik
  3. get_observations - Ambil detail lengkap HANYA untuk ID yang sudah difilter (~500-1.000 token/hasil)

Cara Kerjanya:

  • Claude menggunakan MCP tools untuk mencari memori Anda
  • Mulai dengan search untuk mendapatkan indeks hasil
  • Gunakan timeline untuk melihat apa yang terjadi di sekitar observasi tertentu
  • Gunakan get_observations untuk mengambil detail lengkap untuk ID yang relevan
  • ~10x penghematan token dengan memfilter sebelum mengambil detail

MCP Tools yang Tersedia:

  1. search - Cari indeks memori dengan full-text queries, filter berdasarkan tipe/tanggal/proyek
  2. timeline - Dapatkan konteks kronologis di sekitar observasi atau query tertentu
  3. get_observations - Ambil detail observasi lengkap berdasarkan ID (selalu batch beberapa ID)

Contoh Penggunaan:

// Step 1: Search for index
search(query="authentication bug", type="bugfix", limit=10)

// Step 2: Review index, identify relevant IDs (e.g., #123, #456)

// Step 3: Fetch full details
get_observations(ids=[123, 456])

Lihat Panduan Search Tools untuk contoh terperinci.

Sistem Persyaratan

  • Node.js: 20.0.0 atau lebih tinggi
  • Claude Code: Versi terbaru dengan dukungan plugin
  • Bun: JavaScript runtime dan process manager (diinstal otomatis jika tidak ada)
  • uv: Python package manager untuk vector search (diinstal otomatis jika tidak ada)
  • SQLite 3: Untuk penyimpanan persisten (sudah dibundel)

Catatan Setup Windows

Jika Anda melihat error seperti:

npm : The term 'npm' is not recognized as the name of a cmdlet

Pastikan Node.js dan npm sudah terinstal dan ditambahkan ke PATH Anda. Unduh installer Node.js terbaru dari https://nodejs.org dan restart terminal Anda setelah instalasi.

Claude Code hooks tidak memerlukan Git Bash. Setiap hook menjalankan claude-mem secara langsung, dan npx claude-mem install menempatkan launcher tersebut di %LOCALAPPDATA%\claude-mem\bin\claude-mem.exe serta menambahkan folder ke user Path Anda. Restart terminal atau IDE Anda setelahnya agar Claude Code dapat mendeteksi Path baru. Jika hooks melaporkan Executable not found in $PATH: "claude-mem", jalankan npx claude-mem doctor dan lihat Troubleshooting.

Konfigurasi

Pengaturan dikelola di ~/.claude-mem/settings.json (dibuat secara otomatis dengan nilai default pada eksekusi pertama). Konfigurasikan model AI, port worker, direktori data, level log, dan pengaturan injeksi konteks.

Untuk menyertakan observasi dari setiap harness dalam konteks SessionStart Claude Code dan Codex, atur "CLAUDE_MEM_SESSION_START_INCLUDE_ALL_SOURCES": "true" di file tersebut, atau aktifkan Sertakan semua sumber saat sesi dimulai di pengaturan viewer. Defaultnya adalah "false", yang membatasi konteks startup ke harness saat ini. Batas jumlah observasi tetap berlaku di seluruh sumber yang dipilih.

Lihat Panduan Konfigurasi untuk semua pengaturan dan contoh yang tersedia.

Konfigurasi Mode & Bahasa

Claude-Mem mendukung beberapa mode workflow dan bahasa melalui pengaturan CLAUDE_MEM_MODE.

Opsi ini mengontrol keduanya:

  • Perilaku workflow (misalnya, code, chill, investigation)
  • Bahasa yang digunakan dalam observasi yang dihasilkan

Cara Mengonfigurasi

Edit file pengaturan Anda di ~/.claude-mem/settings.json:

{
  "CLAUDE_MEM_MODE": "code--zh"
}

Mode didefinisikan di plugin/modes/. Untuk melihat semua mode yang tersedia secara lokal:

ls ~/.claude/plugins/marketplaces/thedotmack/plugin/modes/

Mode yang Tersedia

Mode Description
code Default English mode
code--zh Simplified Chinese mode
code--ja Japanese mode

Language-specific modes follow the pattern code--[lang] where [lang] is the ISO 639-1 language code (e.g., zh for Chinese, ja for Japanese, es for Spanish).

Note: code--zh (Simplified Chinese) is already built-in — no additional installation or plugin update is required.

After Changing Mode

Restart Claude Code to apply the new mode configuration.
