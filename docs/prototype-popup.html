Fungsi & Nilai Utama

Ponytail adalah skill agentic AI yang memprogram pola pikir asisten coding (Claude Code, Cursor, Copilot) agar bertindak seperti senior developer paling efisien/malas: menolak menulis kode spekulatif, memangkas boilerplate, dan memaksa penggunaan standard library native.

import { id } from 'date-fns/locale';

interface IDateFormatterService {
  formatDate(raw: string): string;
}

export class CustomDateFormatterService implements IDateFormatterService {
  public formatDate(rawDate: string): string {
    try {
      const parsed = parseISO(rawDate);
      return format(parsed, 'dd MMMM yyyy', { locale: id });
    } catch (err) {
      throw new Error('Failed parsing date');
    }
  }
}

Masalah yang Dipecahkan

Menghentikan Over-Engineering

Mencegah AI membuat interface berlebihan, factory class, atau scaffolding untuk hal yang belum dibutuhkan.

Mencegah Ketergantungan Paket Liar

AI dilarang menginstal package npm/pip baru jika hal tersebut dapat diselesaikan 3-5 baris native.

Menghemat 40-60% Token Context Window

Kode lebih ramping berarti konsumsi token LLM jauh lebih hemat dan respon jauh lebih cepat.

Alur Kerja "The Ladder" Prinsip Ketat
  1. Perlu ada? Jika tidak $\rightarrow$ batalkan (YAGNI).
  2. Sudah ada di repo? Pakai ulang fungsi existing.
  3. Stdlib bisa? Utamakan modul internal runtime.
  4. Fitur native platform? Gunakan CSS/DOM bawaan.
  5. Dependency terpasang? Manfaatkan yang sudah ada.
  6. Bisa 1 baris? Tulis 1 baris kode saja.

Kapan Harus Digunakan?

  • Ketika Anda ingin AI memodifikasi kode tanpa merusak arsitektur existing.
  • Saat ingin menghindari bloated dependencies di project kecil atau microservice.
  • Saat sesi coding panjang agar token limit context window tidak cepat habis.
